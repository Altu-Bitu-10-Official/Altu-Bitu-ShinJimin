# 12. 트리 (Tree)

## 개념
- 비선형 자료구조, 그래프의 부분집합
- 사이클 없음, 정점 V개 → 간선 V-1개
- 부모-자식 계층 구조
- 이진 트리(자식 ≤2) / 일반 트리(제한 없음), 전위·중위·후위·레벨 순회 가능
- 그래프의 일종이므로 DFS/BFS 탐색 가능

## 필수 문제 풀이

### 15681번 - 트리와 쿼리
- 루트에서 DFS 1회, 서브트리 크기 누적 계산
- 방문 배열로 부모 재방문 방지, 쿼리는 미리 계산한 값 O(1) 출력

### 5639번 - 이진 검색 트리
- 전위 순회 첫 값이 루트, [min, root-1] / [root+1, max] 범위로 좌/우 서브트리 재귀 분할
- 재귀 반환 시점에 출력 → 자동으로 후위 순회 순서 완성
