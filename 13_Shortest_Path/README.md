# 13. 최단 경로 (Shortest Path)

## 개념
- 간선에 가중치 있는 그래프에서 정점 사이 최단 경로 구하는 알고리즘
- 하나의 출발지, 모든 도착지(SSP) → 다익스트라, 벨만-포드
- 모든 출발지, 모든 도착지(ASP) → 플로이드-워셜
- 다익스트라: 그리디, 음수 가중치 불가, O(VlogV+ElogV)
- 플로이드-워셜: 모든 정점 쌍 dp 방식, O(V³)

## 필수 문제 풀이

### 1238번 - 파티
- 정방향/역방향 그래프 각각 구성
- X→마을(정방향), 마을→X(역방향) 다익스트라 1회씩 수행
- go_party[i] + go_home[i] 최댓값 출력

### 2458번 - 키 순서
- a<b 비교 결과를 graph[a][b]=1로 구성 후 플로이드-워셜 적용
- graph[i][j] 또는 graph[j][i]가 INF 아니면 비교 가능 관계로 카운트
- 비교 가능 수가 n-1(전원)인 학생 수 출력
